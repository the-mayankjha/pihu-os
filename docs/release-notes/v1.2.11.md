# PIHU OS v1.2.11 — Updates & Frosted Workspace

## Software updates
- Check for updates automatically when PIHU opens and show an update notice when a release is available.
- Review updates in General Settings, including release notes, download progress, downloaded size, installation state, errors and retry actions.
- Installation starts only after choosing Download & install. Restart separately after installation on macOS and Linux.
- Ask PIHU to check application updates, or enter `/update` in the command palette.
- Use public GitHub release download URLs in updater manifests to avoid unauthenticated API asset failures. Package signatures remain required.

## Quiet Desktop Mode & appearance
- Keep Market available while desktop widgets are hidden.
- Preserve frosted glass with a subtle dark tint in Quiet Desktop Mode.
- Add glass tint, background blur, reduced transparency and reset controls.
- Remove the accent-color picker and unify inner Settings surfaces.

## Marketplace
- Refresh the Market header, search field, package cards and install/update states.
- Bring Market forward when opened and register the configured Market shortcut globally, including Cmd+M on macOS.

## Availability
- Windows x64 NSIS installer, Linux x64 DEB/AppImage, and separate Intel/Apple Silicon macOS downloads.
- macOS builds are ad-hoc signed, not Apple-notarized.
- Release publication waits for every platform build and packaged runtime validation.

TypeScript compilation passed. Native shortcut behavior and the new updater interface still require manual device validation; CI packaging checks do not validate every UI interaction.
