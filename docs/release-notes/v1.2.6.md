Fixes the macOS app bundle signature that caused v1.2.5 downloads to be reported as damaged.

## Fixes
- macOS releases now use a complete ad-hoc app bundle signature, including sealed resources, instead of relying on the executable's linker signature.
- The release workflow checks both macOS app bundles with strict code-signature verification before allowing the release draft to be published.
- The local DMG builder preserves app bundle symlinks with ditto and verifies the staged signature before packaging.
- Fixed a missing spawnSync import that prevented ./bin/pihu release from completing.

## Downloads
- macOS: separate DMG installers for Apple silicon and Intel Macs.
- Windows: x64 EXE and MSI installers.
- Linux: x64 AppImage and DEB packages.
- Signed updater artifacts and latest.json are included for in-app updates. Updater signatures are separate from Apple code signing.

## macOS installation
This release is ad-hoc signed, not Apple-notarized. The signature fix addresses the damaged-bundle error; it does not provide Developer ID verification. macOS may still require explicit approval in System Settings → Privacy & Security before first launch.

Download the installer for your Mac, open the DMG, and move Pihu OS to Applications. Existing v1.2.5 downloads are not repaired automatically; use the v1.2.6 installer when available.

## Validation
The original v1.2.5 DMG passed its disk-image checksum and matched the release SHA-256. Its app bundle failed strict signature verification. Applying a complete ad-hoc signature to a temporary copy made that copy pass strict verification. This release's CI additionally verifies the newly built macOS bundles before publication.
