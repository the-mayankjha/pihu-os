# Pihu

Create and select a ChatGPT Work pet based on pihu-mascout.png. Name: Pihu.
Preserve pink glasses, bindi, curly dark ponytail, silver earrings, floral white kurta, blue jeans and pink shoes.
Include readable error/failed reaction, success celebration, and playing with a white cat.
All complete frames must be unclipped and unbroken. Save source art, strips, frames, atlas, reports and motion previews locally.
The supported v2 pet atlas has fixed 192x208 cells; high resolution source strips are retained separately.
State mapping: failed = error/failure; jumping = success celebration; running (active work) = focused cat play.
Generation: built-in image_gen; exact prompts in prompts/.
Library connector is unavailable in this session; local outputs serve as artifact record.

User addition: hair flip and pout frames. Waiting features an expectant pout; review combines inspection and gentle hair-flip/tuck gesture.

User addition: mouth-moving speaking sequence and interaction with another pet/spirit. Waving becomes talking greeting with closed/open mouth cycle.
